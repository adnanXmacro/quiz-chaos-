# Quiz Chaos

Free Android APK for **Quiz Chaos** by **8BiT Softworks** — Bangladesh medical admission prep.

Latest in the app: Recheck, PDF Hub, Mayabi, and an in-app App Market.

## Download

Pages site: https://adnanxmacro.github.io/quiz-chaos-/

APK: [QuizChaos_vanilla.apk](QuizChaos_vanilla.apk)

This repository is the download page only. It does not contain the Quiz Chaos app source.

## Features (in the app)

- Recheck — advisory question audit; scores never change
- PDF Hub — notes and papers
- Mayabi — house guide
- App Market — study apps (Open Tube is one example)
- Daily paper, Houses, streak dragon, 1v1
