# Quiz Chaos: what's new

Feature and update page for **Quiz Chaos** by **8BiT Softworks**, a free Android quiz app for Bangladesh medical admission prep.

- Live site: https://adnanxmacro.github.io/quiz-chaos-/
- Download page (APK and install steps): https://adnanxmacro.github.io/Qq/#download

This repository is the update page only. It does not contain the app source or the APK.

## Screenshots

App screens live in `img/` (720 x 1600 JPG, about 50 to 100 KB each). The leaderboard and profile screens have player names and the account ID blurred. Re-do the blur on any new screenshot that shows other people's data.

## Adding a new update

In `index.html`, copy one `<article class="entry">` block, paste it at the top of the list, and edit the text.

## GitHub Pages

Enable Pages on `main` / `/ (root)`.
