New in the app

Each of these sits alongside the daily paper, so you can use it mid-session and get straight back to the quiz.

Recheck

Check a question without leaving the paper.

Audit the stem, the options and the answer key while you are still on the question. Recheck is advisory only, so it never changes a score.

PDF Hub

Notes and papers, kept next to the daily.

Your study notes and papers live as folders inside the app. Open what you need, then go back and sit the quiz.

Mayabi

A guide to Houses, ranks and 1v1.

Mayabi explains how pages, ranks and duels work. Quiz help is optional and switches on only when you paste your own API key on your device.

Questions about this update

Does Recheck change my score?

No. Recheck is advisory only. It audits the stem, options and key, and never changes a score.

Do I need an API key to use Mayabi?

Only for quiz help. Mayabi’s guidance on pages, ranks and 1v1 works as it is, and quiz help unlocks when you paste your own API key on your device.

What is the App Market?

A catalogue of study apps that the team keeps for students and links from inside Quiz Chaos. Every listing is on the 8BiT Softworks store.

Use the download page on the main Quiz Chaos site. It has the APK, the install steps and the full feature list.
